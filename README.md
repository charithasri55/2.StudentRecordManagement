# Student Record Management System

## Overview

A simple **CLI-based Student Record Management System** developed using Java. It allows users to manage student records through a menu-driven console application.

## Features

* Add student records
* View all student records
* Update student details
* Delete student records
* Exit the application

## Technologies Used

* Java
* VS Code
* `ArrayList`
* `Scanner`

## Concepts Used

* Classes and Objects
* Constructors
* Encapsulation
* Getters and Setters
* ArrayList
* CRUD Operations
* Loops and Switch Statements

## How to Run

Compile the program:

```bash
javac Student.java StudentManagementSystem.java
```

Run the program:

```bash
java StudentManagementSystem
```

## Learning Outcome

This project helped me practice **Java OOP concepts, collections, user input, CRUD operations, and menu-driven programming**.
